Why this product exists

ResumePR helps users tailor resumes without losing trust in the final wording.

Problem

Most resume tools either give a shallow ATS score or rewrite content so aggressively that the user stops trusting it.

Approach

This product keeps the user in control by surfacing targeted, job-aware suggestions against the original resume text.

Built with

React, FastAPI, Firebase Auth, local NLP tooling, and free-tier AI providers for practical portfolio-ready deployment.

Workflow

How ResumePR moves from job posting to polished export.

Step 01Review flow

Upload a source resume

Import a PDF or DOCX resume so ResumePR can parse the structure into summary, skills, education, and experience bullets.

Step 02Review flow

Ingest a job description

Paste a job URL, paste raw text, or use the extension to pull the job description from the page you are already viewing.

Step 03Review flow

Review the skills gap

Inspect matched keywords, missing requirements, ATS red flags, and section-by-section alignment before making any changes.

Step 04Review flow

Approve only the edits you trust

Generate targeted AI suggestions, accept or reject them one by one, then save a new version and export the final document.

Install

Set up the full stack locally.

The repo already contains the web app, API, and Chrome extension. These are the core steps users need before trying the product.

git clone https://github.com/Whauv/ResumePR.git
cd ResumePR
npm run dev:web
uvicorn resumepr_api.main:app --reload --app-dir apps/api/src

1. Clone and configure

Clone the repo, create the backend and frontend env files, and add your Firebase plus Groq or Gemini credentials.

2. Start the backend

Install Python dependencies, download the spaCy model, and run the FastAPI server on port 8000.

3. Start the frontend

Install the Vite app dependencies and run the web client on port 5173.

4. Load the extension

Enable Chrome developer mode, load the unpacked extension folder, and start sending job descriptions into the product.
